# Using a knowledge base

- **AI settings:** Connect OpenRouter with PKCE, or paste an OpenRouter/Anthropic key. Choose fast and smart models. Keys are held in the current tab's memory and temporarily in server memory while processing requests; they are never written to browser storage, server storage, logs or backups. Closing the tab clears its copy; an already-running ingestion job may retain credentials in memory until it finishes. Previously remembered keys are removed from browser settings on startup. The chosen provider receives prompts and relevant source context, using your own budget.
- **Files:** PDF, slides saved as PDF, PNG/JPEG/WebP, DOCX, PPTX, XLSX, HTML, EPUB, Markdown and text. The hosted file limit is 5 0 MiB; one upload batch is limited to 1 0 0 MiB. Standard PDF ingestion needs selectable text; scanned pages require the visual slide option with a vision-capable provider or external OCR. Hosted audio/video is rejected. Self-hosted A/V remains optional.
- **Questions:** Fast mode uses fewer AI calls and skips decomposition/reflection. Thorough mode runs the complete Self-RAG checks. Dense, graph and hybrid retrieval remain selectable.
- **Citations:** Click a numbered answer citation to open its source at the supporting passage. PDF previews use the cited page and highlight the matching text; Word previews scroll to the matching paragraph and retain explicit page breaks. Word preview pagination can differ from Microsoft Word. Slide citations retain the slide number. Other formats show the extracted passage and an original-file link. The evidence count distinguishes retrieved passages from passages actually cited in the answer; several passages can come from one file. Original files remain in your browser; unavailable originals fall back to the complete extracted passage. Failed reuploads keep the previously saved originals; new originals become available after successful ingestion.
- **Graph:** Turn editing on. Drag nodes to arrange them; Shift-drag connects; Ctrl-drag selects; right-click opens actions. Add Markdown/LaTeX notes, link with `[[concept names]]`, edit content/terms, merge duplicates, and undo/redo. Node positions are saved. Topic collapse, reasoning paths, neighborhood highlights, spacing and PNG export are retained.
- **Connections:** The Topic → Subtopic → Content hierarchy stays directed. Other connections are plain, undirected lines between distinct concepts. New automatic connections require supporting source passages; they do not imply causation, agreement or a prerequisite. Manual links and note links retain independent backing, so removing one does not erase the others. Older backups migrate without paid AI checks and keep unknown provenance marked as legacy.
- **Storage:** Switch knowledge bases in the toolbar. Export a `.lumin` backup to move to another device/profile. Imports include original files, graph, vectors, conversations; keys are excluded. Save backups before clearing browser data. Persistent-storage requests reduce eviction risk but do not replace backups.
- **Recovery:** The server cache can sleep or disappear. The app restores the selected knowledge base from IndexedDB and resumes known upload jobs, including after reconnecting or opening another tab. Each knowledge base accepts one browser upload at a time; other tabs receive a wait message. This coordination requires HTTPS (or localhost) and a current browser with Web Locks. Export waits until its upload has finished so the backup contains matching source originals. Keep the app open until processing is complete. If a tab closes before an upload's job is confirmed, or its final status is unavailable, saved originals are kept and the app explains how to retry. Re-upload those files to confirm processing and refresh their previews. Older overlapping uploads with an uncertain original order also require an explicit re-upload.
